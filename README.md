# Rick Clips Video Engine

An AI-assisted animated video production system.

## Production Pipeline

1. AI script generation
2. ElevenLabs voiceover generation
3. Scene-by-scene visual generation
4. Animated graphics and transitions
5. Background music and sound effects
6. Automatic video assembly
7. MP4 rendering and export

## Technology

- Three.js
- JavaScript
- ElevenLabs
- GitHub Actions
- AI-assisted animation

## Goal

Produce polished YouTube videos with an automated
and affordable production workflow.
